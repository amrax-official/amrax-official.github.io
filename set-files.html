Set Files

Download ready-to-use .set configurations for MetaTrader 5. Every profile is grouped by risk and backed by a real-tick backtest.

How to load a set file: Open MT5 → right-click your chart → Expert Advisors → Load → select the downloaded .set file. Alternatively: EA properties → Inputs → Load.

Risk notice: Higher ROI profiles carry higher drawdown. Always test on a demo account first. Past performance is not indicative of future results.

Lot Mode is read directly from each .set file. Fixed = manual fixed lot. Sequence = starts at 0.01 and adds 0.01 after every N trades (N = repeat count). Min Capital = max drawdown on a $1,000 test account + a small buffer.

Based on a $1,000 test account. ROI and drawdown percentages are calculated on $1,000. Minimum capital is the smallest balance that covers each profile's historical max drawdown in dollars, plus a small buffer — on a smaller balance, the same fixed-lot trades show a higher percentage drawdown.
